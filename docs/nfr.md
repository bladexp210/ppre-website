Fill this file when the now-node becomes ready. A blank row is a fail. “Not this product” needs a reason in the third column. Do not mark the node ready while any value cell is blank.

Modularity says how a later branch is added or removed without rewriting the others, and the depth cap. The default cap is 3. A product may lower it, not raise it.

Product observability is an NFR row. See docs/index.md.
