# Small-sample warning

One decision. It applies to the IPIP-NEO-120 build only. It does not apply to the Understanding Society build.

When a group has fewer than 30 respondents, the site still shows the comparison and flags it with this warning: "this comparison is based on a small sample, so read it with caution." Thirty respondents per group is the threshold. The warning appears inline with the answer sentence, not as a banner above the tiles, so it stays attached to the claim it qualifies.

The human stated this decision on 31 Oct 2026, updated the wording and placement the same day, and set the cutoff at 30 per group.

Status: accepted. Threshold: fewer than 30 respondents per group.
