# Fill-in-the-blank question

One decision. It applies to the IPIP-NEO-120 build only. It does not apply to the Understanding Society build.

The question pattern is locked. The question sentence is: "How do [group one] compare to [group two] on [trait or facet]?"

Each group is defined independently by sex and age band. For example, men aged 18–24 versus women aged 35–44, or older men versus younger men.

The trait or facet is the single shared comparison point. Both groups are compared on the same trait or facet only, never different traits against each other. That slot offers 35 options: 30 facets plus the 5 broad traits the facets compose — openness, conscientiousness, extraversion, agreeableness, and neuroticism.

Country is dropped as a filter.
