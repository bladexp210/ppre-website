# Derived shocks are filter choices

One decision. It applies to the Understanding Society build only. It does not apply to the IPIP-NEO-120 build.

Derived shocks (job loss, divorce, health shocks, built from changes in work, partnership, and health across waves) should be exposed as filter choices in the fill-in-the-blank interface, not hidden. Users can filter by them directly.

The human stated this decision on 31 Oct 2026 and asked that it be recorded for the Understanding Society build.

Status: accepted
