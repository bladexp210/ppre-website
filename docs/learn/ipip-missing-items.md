# Missing item answers

One decision. It applies to the IPIP-NEO-120 build only. It does not apply to the Understanding Society build.

Item values of 0 are missing. They are skipped items, not a neutral answer. When computing a facet score or a trait score, drop the zeros and average only the items the person answered. This applies to all 30 facets and all 5 traits.

For example, if someone skipped 3 anxiety items, their anxiety score is the average of the anxiety items they did answer. The scoring key gives anxiety 4 items.

If every item in that score was skipped, there is no score for it.

The human stated this decision on 31 Oct 2026 and asked that it be recorded for the IPIP-NEO-120 build.

Status: accepted
