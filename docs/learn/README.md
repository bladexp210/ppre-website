# Lessons

Learning loops land here. They do not push a tree node or a C4 scope.

One draft per lesson, in this directory. The human accepts or rejects it in the file:

```text
Status: accepted
```

or

```text
Status: rejected
```

A chat “yes” is not the end.

Repair attempt 2, a repeated failure class, or a human request to keep a rule may create one draft. A repair turn cannot promote that draft. Promotion happens only after the human marks the lesson reusable across projects, and the write lands in the framework kit repository.
