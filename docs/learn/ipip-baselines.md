# Baselines

One decision. It applies to the IPIP-NEO-120 build only. It does not apply to the Understanding Society build.

Add a sex-only baseline (all men, all women) as an additional reference point alongside the whole-population baseline. The whole-population baseline includes rows with missing age. The sex baseline is the one other baseline worth having. An age baseline is not useful because age is already the slicing variable.

The human stated this decision on 31 Oct 2026 and asked that it be recorded for the IPIP-NEO-120 build.
