# Answer layout

One decision. It applies to the IPIP-NEO-120 build only. It does not apply to the Understanding Society build.

The answer starts with a plain-English verdict sentence. For example: "Men aged 18–24 scored higher on neuroticism anxiety than women aged 35–44. The difference is a small shift, hard to notice in everyday life."

The overlap percentage is tucked away behind a hover. It is not shown in the sentence.

See docs/index.md.

Below the sentence, statistical tiles display the raw numbers: mean, standard deviations, Cohen's d, and other key figures. Hovering any tile shows a plain-English explanation of that term. Hovering "small shift" reveals the number for that comparison, for example 0.3. Hovering Cohen's d reveals its meaning.

Cohen's d labels, using the absolute value:

- Under 0.2: negligible.
- From 0.2 up to 0.5: small. 0.5 itself is medium.
- From 0.5 up to 0.8: medium. 0.8 itself is large.
- 0.8 and up: large.

The human stated this decision on 31 Oct 2026 and set these four labels the same day.

Status: accepted. Thresholds: negligible under 0.2; small from 0.2 up to 0.5; medium from 0.5 up to 0.8; large at 0.8 and up.
