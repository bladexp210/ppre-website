Variables in the IPIP120.dat file are organized in the format below. CASE numbers refer to the numbering in the original, which is why the numbers run higher than the N of 619,150. For SEX, 1 = male; 2 = female. SEC, MIN, HOUR, DAY, MONTH, and YEAR were generated by the Perl localtime function. The first three of these variables show the time of day the inventory was completed. DAY indicates the day of the month, and MONTH values range from 0 (January) to 11 (December). YEAR contains the number of years since 1900, so to obtain a four-digit year, add 1900 to this variable.


The 120 items, I1 to I120 contain values from 1 to 5, with missing values coded as 0. For forward-scored items, the values 1 to 5 refer to the item responses Very Inaccurate, Moderately Inaccurate, Neither Accurate nor Inaccurate, Moderately Accurate, and Very Accurate. Reverse-scored items were recoded (1=5, 2=4, 4=2, 5=1) at the time the respondent completed the inventory, so values for these items can simply be added without recoding when scale scores are computed. But that also means that researchers interested in measuring the number of consecutive uses of the same response category will have to recode reverse-scored items to have the values correspond to Very Inaccurate = 1 through Very Accurate = 5.
