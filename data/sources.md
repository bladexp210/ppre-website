# IPIP-NEO-120 sources

Accessed 31 Oct 2026. Local copies are under `data/`.

| Source | URL | What was obtained |
| :--- | :--- | :--- |
| OSF project page | https://osf.io/wxvth/ | The page that lists the 120-item files and the 300-item files. |
| OSF wiki | https://osf.io/wxvth/wiki/home | `IPIP120.dat` has 619,150 cases. `DAT120.doc` describes the formatting. A portable SPSS copy is listed too. No age range, sex codes, or reverse-item list. |
| IPIP120.dat | https://osf.io/download/q9jrh/ | `data/IPIP120.dat`, 94,729,950 bytes. Fixed-width item responses. |
| DAT120.doc | https://osf.io/download/hgm7n/ | `data/DAT120.doc`, 36,864 bytes. Column map: sex, age, country, items I1–I120. Says reverse-scored items were already recoded in the file and does not name which items. `data/DAT120.md` is a local table of that same guide. |
| IPIP120.por.zip | https://osf.io/download/t4rms/ | `data/IPIP120.por.zip`. Portable SPSS copy of the same 120-item file, from the same OSF page. |
| Scoring key | https://osf.io/ycvdk/ | `IPIP-NEO-ItemKey.xls` from https://osf.io/download/yk3fd/. Mapped into `data/ipip120-scoring-key.md`: I1–I120, facet, trait, and reverse-keyed items. |

Johnson’s IPIP site was not used. The item-to-facet key was not taken from there.

## Citation

Referencing and citing the original data is required. This is a standing rule for full auditability and transparency.

Johnson, J. A. (2014). Measuring thirty facets of the Five Factor Model with a 120-item public domain inventory: Development of the IPIP-NEO-120. *Journal of Research in Personality, 51,* 78–89. https://doi.org/10.1016/j.jrp.2014.05.003

Data: Johnson, J. A. (2014). IPIP-NEO-120 item responses, N = 619,150. https://osf.io/wxvth/
